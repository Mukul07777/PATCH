How it works

From advisory to verified PR.

  1. Add a project

    Paste a GitHub URL or upload a requirements.txt, pyproject.toml or lock file.

  2. Scan and rank

    Every pin is checked on OSV.dev and ranked with EPSS and the CISA KEV list. No code is run.

  3. Fix and prove

    The agent upgrades, repairs the code until pytest is green, then re-runs the exploit. You review the PR.
