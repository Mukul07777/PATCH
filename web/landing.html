The loop

Find.Fix.Ship.

Security PRs rot because version bumps break builds. PatchPilot doesn't stop at the bump: it runs your tests, reads the failures, patches the code and escalates to a bigger model until everything passes.

Inside the agent →

How it works

  1. Add a project. Paste a GitHub URL, or upload a requirements.txt, pyproject.toml, poetry.lock, uv.lock or Pipfile.lock.
  2. Scan. Every pinned version is checked on OSV.dev and ranked with EPSS and the CISA KEV list. No API key, no code execution.
  3. Fix with the agent. For GitHub projects with a test suite, PatchPilot upgrades the pins, repairs the code until tests pass and prepares a PR.
